# Funny Codes

مجموعه‌ای از پروژه‌های سرگرمی و کوچک پایتون که برای تمرین، لذت و یادگیری نوشتم.

## پروژه‌ها
- **ColorWheel** — چرخ رنگ و افکت‌های گرافیکی
- **RockPaperScissors** — بازی سنگ‌کاغذ-قیچی
- **Guess** — بازی حدس عدد
- **PassGenerator** — ژنراتور رمز عبور قوی
- **.FunnyCodes** — پروژه‌های متفرقه

## تکنولوژی‌ها
- Python
- Tkinter (رابط گرافیکی)
- Random, Time و ...

## نحوه اجرا

```bash
git clone https://github.com/AliHasanpourdev/funny-codes.git
cd funny-codes

pip install -r requirements.txt

# مثال:
cd RockPaperScissors
python main.py
```

این پروژه‌ها بیشتر جنبه آموزشی و سرگرمی دارن.
